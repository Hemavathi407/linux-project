Linux Security Dashboard

Project Overview

Linux Security Dashboard is a security monitoring project designed to monitor Linux system activities, identify suspicious events, and generate security alerts.

Problem Statement

Linux systems generate many log records. Manually monitoring these logs is difficult and can cause important security threats to be missed.

Proposed Solution

This project provides a simple dashboard to monitor system logs, identify suspicious activities, and generate alerts for potential security issues.

Installation and Execution

1. Clone the repository:
   "git clone https://github.com/Hemavathi407/linux-project.git"

2. Open the project folder:
   "cd linux-project"

3. Run the backend according to the dependencies and entry point in "backend/app.py".

4. Open the frontend "index.html" in a browser.
